## TeleportVehicle

[English is here](./README.md)

### 概要
ビークルテレポーターツールを提供し、ビークルを選択して現在地にテレポートできます。遠距離にあるビークルや紛失したビークルを長距離移動なしで回収するのに最適です。

### 機能
- **ビークルテレポーターツール**: スキャナーコンポーネントを使用したクラフト可能な携帯デバイス
- **右クリック選択**: 利用可能なビークル（シーモス・プラウンスーツ）を順次選択
- **左クリックテレポート**: 選択したビークルを現在地にテレポート
- **スマート検出**: ドックされていない配置済みビークルのみを表示
- **視覚・音響エフェクト**: ワーパー風のテレポートエフェクトとサウンド
- **安全チェック**: ドックされたビークルのテレポートを防止

### レシピ
**ビークルテレポーター:**
- スキャナー x1
- ダイヤモンド x2
- リチウム x2
- パワーセル x2

### 使い方
1. ファブリケーター（個人用 > ツール）からビークルテレポーターをクラフト
2. ツールを手に装備
3. **右クリック**で利用可能なビークルを順次選択
4. **左クリック**で選択したビークルを現在地にテレポート
5. ビークルはプレイヤーの前方3メートル、上方1メートルの位置に出現

### 必要環境
- BepInEx 5.x（Subnautica 用）
- Nautilus
- Subnautica（PC 版）

### 導入
`TeleportVehicle.dll` と `Localization` フォルダを `Subnautica/BepInEx/plugins/TeleportVehicle/` に配置します。

### ビルド
```bash
./build.sh
```
出力：`bin/Release/net472/TeleportVehicle.dll`
