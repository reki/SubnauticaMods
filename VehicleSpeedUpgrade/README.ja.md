## VehicleSpeedUpgrade

[English is here](./README.md)

### 概要
設定可能な倍率とバッテリー消費機能を備えた、すべてのSubnauticaビークル用の包括的な速度向上Modです。

### 機能

このModでは、以下の4つの速度アップグレードモジュールを追加します：

- **ビークル速度アップグレード MK1**: シーモス・プラウンスーツ用（設定可能倍率、デフォルト2.0倍）
- **ビークル速度アップグレード MK2**: シーモス・プラウンスーツ用（設定可能倍率、デフォルト2.5倍）
- **サイクロプス速度アップグレード MK1**: サイクロプス潜水艦用（エンジンモード別設定可能）
- **サイクロプス速度アップグレード MK2**: サイクロプス潜水艦用（高性能版）

### 主要機能

- **汎用対応**: シーモス・プラウンスーツ・サイクロプスに対応
- **設定可能な倍率**: JSON設定ですべての速度値を調整可能
- **バッテリー消費**: バランス調整のためのオプション電力消費システム
- **エンジンモード対応**: サイクロプスモジュールはエンジン速度（低速/標準/高速）に基づいて調整
- **ダメージ防御**: 速度モジュール装着時のオプション耐久性向上

### 作成場所
- **MK1**: ビークルアップグレード装置（SeamothUpgrades > CommonModules）
- **MK2**: 改造ステーション（Workbench）
- **サイクロプス MK1**: サイクロプス・ファブリケーター（Modules）
- **サイクロプス MK2**: 改造ステーション（Workbench）

### 設定
Modには広範囲なカスタマイズオプションを持つ `config.json` ファイルが含まれます：
- **速度倍率**: すべてのビークルと方向の推力倍率を調整
- **エネルギー消費**: 各モジュールのバッテリー消費率を設定
- **デバッグオプション**: トラブルシューティング用の詳細ログを有効化
- **ダメージ防御**: 強化された耐久性抵抗を切り替え

### 使用上の注意
- モジュールはビークルのアップグレードスロットに装着してください
- ビークル1台につき速度モジュール1個（上位版が下位版を上書き）
- サイクロプスモジュールは現在のエンジンモードに基づいて性能を調整
- エネルギー消費は移動に比例（設定可能）
- すべての設定は設定ファイルで変更可能

### 必要環境
- BepInEx 5.x（Subnautica 用）
- Nautilus
- Subnautica（PC 版）

### 導入
`VehicleSpeedUpgrade.dll` と `Localization` フォルダを `Subnautica/BepInEx/plugins/VehicleSpeedUpgrade/` に配置します。

### ビルド
```bash
./build.sh
```
出力：`bin/Release/net472/VehicleSpeedUpgrade.dll`
