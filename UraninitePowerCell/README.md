## UraninitePowerCell

[日本語はこちら](./README.ja.md)

### Overview
Adds high-capacity power cells and batteries crafted from Uraninite Crystal. These advanced power sources provide exceptional capacity for extended expeditions and power-hungry equipment.

### Features
- **Uraninite Power Cell**: 10,000 units capacity (50x standard Power Cell's 200 units)
- **Uraninite Battery**: 10,000 units capacity (100x standard Battery's 100 units)
- **Full Compatibility**: Works with all vehicles, tools, and chargers
- **Custom Icons**: Distinctive visual appearance for easy identification
- **Nuclear Waste Disposal**: Can only be disposed of in Nuclear Waste Disposals, not regular trash cans

### Recipes
**Uraninite Power Cell:**
- Power Cell x1
- Uraninite Crystal x2
- Lithium x1
- Silicone Rubber x1

**Uraninite Battery:**
- Battery x1
- Uraninite Crystal x2
- Lithium x1
- Silicone Rubber x1

### Unlock Requirements
- Scan Uraninite Crystal to unlock both recipes
- Craft at Fabricator (Resources > Electronics)

### Requirements
- BepInEx 5.x for Subnautica
- Nautilus
- Subnautica (PC)

### Install
Copy `UraninitePowerCell.dll` and the `Localization` folder into `Subnautica/BepInEx/plugins/UraninitePowerCell/`.

### Build
```bash
./build.sh
```
Output: `bin/Release/net472/UraninitePowerCell.dll`.
