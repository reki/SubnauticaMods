## UraninitePowerCell

[English is here](./README.md)

### 概要
閃ウラン鉱から作成される大容量パワーセル・バッテリーを追加します。これらの先進的な電源は、長期探索や電力消費の激しい機器に対して優れた容量を提供します。

### 機能
- **閃ウラン鉱パワーセル**: 容量10,000ユニット（標準パワーセル200ユニットの50倍）
- **閃ウラン鉱バッテリー**: 容量10,000ユニット（標準バッテリー100ユニットの100倍）
- **完全互換性**: すべてのビークル、ツール、充電器で使用可能
- **カスタムアイコン**: 識別しやすい独特な外観
- **核廃棄物処理**: 通常のゴミ箱ではなく、核廃棄物処理装置でのみ廃棄可能

### レシピ
**閃ウラン鉱パワーセル:**
- パワーセル x1
- 閃ウラン鉱 x2
- リチウム x1
- シリコンゴム x1

**閃ウラン鉱バッテリー:**
- バッテリー x1
- 閃ウラン鉱 x2
- リチウム x1
- シリコンゴム x1

### アンロック条件
- 閃ウラン鉱をスキャンして両レシピをアンロック
- ファブリケーター（基本素材 > 電子部品）で作成

### 必要環境
- BepInEx 5.x（Subnautica 用）
- Nautilus
- Subnautica（PC 版）

### 導入
`UraninitePowerCell.dll` と `Localization` フォルダを `Subnautica/BepInEx/plugins/UraninitePowerCell/` に配置します。

### ビルド
```bash
./build.sh
```
出力：`bin/Release/net472/UraninitePowerCell.dll`
